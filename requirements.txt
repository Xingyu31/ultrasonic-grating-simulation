# 
# 1. 确保已安装 Node.js (版本 >= 16.x)

# 
# 2. 进入项目目录
#    cd ultrasonic_grating_v3
# 
# 3. 安装依赖
#    npm install --legacy-peer-deps
# 
# 4. 启动开发服务器
#    npm run dev
# 
# 5. 打开浏览器访问
#    http://localhost:5174/

# ========================================================
# 常见问题
# ========================================================
# 
# Q: 安装依赖时报错 "UNMET PEER DEPENDENCY"
# A: 使用 npm install --legacy-peer-deps 命令安装
# 
# Q: 启动时报错 "Cannot find module"
# A: 确保已正确安装依赖，尝试删除 node_modules 后重新安装
# 
# Q: 热更新不生效
# A: 检查 vite.config.js 配置，确保没有配置错误
# 
# Q: 切换视图后仿真进度丢失
# A: 项目已使用 KeepAlive 保持状态，切换视图时进度不会丢失
# 
# ========================================================
# 项目功能模块
# ========================================================
# 
# 1. 仪器仿真界面 (SimulationView.vue)
#    - 仪器拖拽与布局
#    - 实验模式选择器（光波长影响/超声频率影响/液体浓度影响）
#    - 仪器交互控制（激光、水槽、望远镜、CCD相机、信号发生器）
#    - 光学连接效果
# 
# 2. 数据测量界面 (MeasurementView.vue)
#    - 参数设置（浓度、波长、频率、振幅、距离、狭缝宽度）
#    - 衍射光斑图样绘制（Canvas）
#    - 游标读数功能
#    - 衍射光强分布曲线
#    - 数据拟合分析
#    - 分析与验证程序
# 
# 3. 实验报告生成 (ReportView.vue)
#    - 三段式报告（三个实验方向各一段）
#    - 光路流程图（SVG绘制）
#    - 数据表格、拟合结果、分析与结论
#    - 打印和保存功能
# 
# 4. 辅助组件
#    - ZoomModal.vue：双击放大模态框
#    - WelcomePage.vue：欢迎界面
#    - TableZoomModal.vue：表格放大模态框
#    - 仪器SVG组件：LaserSvg、CollimatorSvg、CellSvg、TelescopeSvg、CcdSvg等
#    - 仪器模态框：LaserModal、CellModal、GeneratorModal、RailModal、ScreenModal等
#

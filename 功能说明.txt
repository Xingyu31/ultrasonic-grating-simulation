超声光栅衍射仿真实验（第三版）功能说明
================================================

一、仪器仿真界面
----------------

1. 仪器拖拽与布局
   - 支持从工具栏拖拽激光、平行光管、超声光栅水槽、望远镜、CCD相机、信号发生器、计算机等仪器到操作面板
   - 仪器可通过鼠标左键拖动进行位置调整，每个仪器作为独立Frame存在
   - 信号发生器自动放置在超声光栅水槽下方，计算机放置在CCD相机下方
   - 添加光学导轨、中心线、仪器放置提示和光学连接线，指导仪器排放
   - 仪器下方灰色条已移除，整体视觉更加简洁

2. 实验模式选择器
   - 顶部工具栏提供三个实验方向按钮：光波长影响、超声频率影响、液体浓度影响
   - 选中后显示变量参数（红色高亮）和固定参数（绿色）
   - 测量数据自动标记当前实验模式，实验报告按模式分类显示
   - 测量界面和仪器仿真界面的实验模式双向联动

3. 仪器交互控制
   - 激光：点击开关按钮开启/关闭，开启后激光透镜变红
   - 超声光栅水槽：可调节液体浓度、超声频率、超声振幅参数
   - 望远镜：可调节焦距，对焦状态影响光斑清晰度
   - CCD相机：显示当前实验参数下的衍射光斑，对焦状态影响显示效果（2px/6px线宽）
   - 信号发生器：显示超声频率和振幅参数，与水槽联动
   - 点击"确认参数"保存数据，数据自动同步到测量界面和实验报告

4. 光学连接效果
   - 激光开启后显示红色渐变光束效果，带有光晕
   - 平行光管、望远镜、CCD相机之间有光学连接线
   - 连接线采用黄色半透明细线（2px，0.3透明度），视觉效果柔和不突兀

5. 状态保持
   - 使用 KeepAlive 保持组件状态
   - 切换视图时仿真进度不会清空（仪器位置、步骤进度、激光状态等）


二、数据测量界面
----------------

1. 参数设置
   - 液体浓度（0-30 wt%）：通过滑块和输入框调节
   - 入射波长（380-700 nm）：覆盖可见光范围，颜色随波长变化
   - 超声频率（4-15 MHz）：调节超声波激励频率
   - 超声振幅（0-100%）：调节超声波振幅
   - 水槽到光屏距离（0.1-0.6 m）：调节光路长度
   - 狭缝宽度（0.005-0.02 m）：调节狭缝宽度
   - 环境温度：固定为20°C常数，在标题栏醒目显示

2. 衍射光斑图样
   - 基于Canvas动态生成光斑，支持多层渐变效果
   - 光斑为垂直直线，长度占画布高度的85%
   - 渐变层次：外光晕→中光晕→垂直渐变主体→核心高光渐变→白色亮芯
   - 中心最亮，两端逐渐变暗，形成层次感
   - 光斑颜色根据入射波长自动调整（紫光→蓝光→青色→绿色→黄色→橙色→红色）

3. 游标读数功能
   - 两个圆环形游标（红色游标1、绿色游标2）
   - 点击按钮激活游标，激活状态下点击光斑图放置游标
   - 支持左右调节按钮精确控制游标位置（±0.01 mm）
   - 自动读数功能：点击按钮自动计算+1级和-1级衍射光斑位置并填入输入框
   - 未激活游标时点击光斑图不会放置游标

4. 衍射光强分布曲线
   - 显示衍射条纹的光强分布
   - 横坐标范围固定：-15 ~ 15 mm
   - 纵坐标范围固定：-0.05 ~ 1.05
   - 采用深蓝色（#1e40af）曲线，带有半透明填充效果
   - 高阶衍射条纹强度公式：0.85 - |m| × 0.1（最小值0.15）

5. 测量逻辑（物理公式）
   - 声速由浓度决定：v = 1500 + 10c（c为浓度）
   - 条纹间距公式：D = 2kλfL/v
   - 固定浓度时，改变波长或频率，声速保持恒定
   - 条纹间距随波长/频率正比例变化


三、数据拟合分析
----------------

1. 三种实验模式
   - 液体浓度影响：固定波长和频率，改变浓度，验证声速与浓度的线性关系（v = 1500 + 10c）
   - 光波长影响：固定频率和浓度，改变波长，验证声速恒定（λ变化，v不变）
   - 超声频率影响：固定波长和浓度，改变频率，验证声速恒定（f变化，v不变）

2. 拟合图表
   - 根据当前实验模式绘制拟合曲线
   - 横坐标为变量参数，纵坐标为声速
   - 实验数据点以散点形式显示
   - 拟合曲线为水平直线（波长/频率模式）或斜线（浓度模式）

3. 实验模式信息提示
   - 单行紧凑横幅显示当前实验模式
   - 红色高亮显示变量参数，绿色显示固定参数
   - 显示当前实验模式的理论公式

4. 数据记录与导出
   - 实验记录表包含：序号、波长、频率、浓度、间距、声速
   - 支持添加、删除记录
   - 双击表格可放大查看详细数据
   - 支持导出CSV格式文件
   - 数据自动标记实验模式，用于实验报告分类


四、分析与验证程序
------------------

1. 数据分析指标
   - 实验声速：测量数据的平均值
   - 理论声速：根据浓度计算（v = 1500 + 10c）
   - 相对误差：实验值与理论值的偏差百分比
   - 标准差：数据离散程度
   - 变异系数：相对离散程度
   - 中位数、极差、四分位距：统计分析指标
   - 异常值检测：识别超过3倍标准差的数据点

2. 分模式验证逻辑
   - 波长/频率模式：验证声速恒定，标准差 < 6 m/s 为优秀
   - 浓度模式：验证线性拟合参数，斜率接近10，截距接近1500

3. 拟合参数验证
   - 波长/频率模式：显示声速恒定验证指标和当前标准差
   - 浓度模式：显示拟合斜率、斜率误差、拟合截距、截距误差

4. 验证结果与建议
   - 数据一致性评级：优秀/良好/一般/较差
   - 验证状态：符合理论预期或偏差较大
   - 针对性改进建议：根据误差大小给出改进方向


五、实验报告生成
----------------

1. 三段式报告结构
   - 第一段：光波长对衍射条纹的影响
   - 第二段：超声频率对衍射条纹的影响
   - 第三段：液体浓度对声速的影响

2. 每段报告包含
   - 实验目的：明确该方向的实验目标
   - 实验原理：详细解释物理原理和公式
   - 实验装置与光路图：SVG绘制的光学流程图（激光器→平行光管→超声光栅水槽→望远镜→CCD相机→计算机）
   - 实验数据记录：表格显示测量数据和平均声速
   - 数据处理与分析：实验声速、理论声速、相对误差、标准差、数据一致性
   - 实验结论：自动生成的实验结论

3. 报告状态指示
   - ✓ 已完成（≥3组数据）
   - ◐ n组数据（部分完成）
   - ○ 未开始（无数据）

4. 导出功能
   - 打印报告：调用浏览器打印功能
   - 保存报告：导出为HTML文件


六、交互功能
------------

1. 双击放大功能
   - 衍射光斑图样、光强分布曲线、拟合图表、实验记录表均支持双击放大
   - 放大后支持滚轮缩放、拖拽平移、双击复位
   - 可通过点击关闭按钮、背景区域或按Escape键关闭

2. 提示与通知
   - 参数超出合理范围时弹出提示
   - 操作成功/失败时显示通知
   - 数据不足时给出提示

3. 响应式布局
   - 三栏布局比例：左侧30%（参数设置+拟合分析）、中间45%（光斑图样）、右侧25%（测量+验证）
   - 面板可自适应窗口大小


七、物理原理总结
----------------

光栅方程：λₛ × sinθₖ = kλ

近似条件：sinθₖ ≈ tanθₖ = Dₖ / (2L)

条纹间距：D = 2kλLf / v

声速公式：v = 1500 + 10 × c

其中：
- λₛ：超声光栅常数
- θₖ：k级衍射角
- k：衍射级次（取k=1）
- λ：入射光波长
- D：±1级衍射条纹间距
- L：水槽到光屏距离
- f：超声频率
- v：声速
- c：液体浓度（wt%）


技术栈：Vue 3 + Element Plus + Canvas + SVG + Vite

# ========================================================
# 一、硬件配置要求
# ========================================================

## 1. 处理器 (CPU)

### 最低配置
- 处理器类型：Intel Core i3-4160 或 AMD A8-7600 及以上
- 核心数：双核四线程及以上
- 基础频率：3.0 GHz 及以上
- 缓存：3MB L3 缓存及以上

### 推荐配置
- 处理器类型：Intel Core i5-10400F 或 AMD Ryzen 5 5600G 及以上
- 核心数：六核十二线程及以上
- 基础频率：3.0 GHz 及以上
- 缓存：8MB L3 缓存及以上

### 说明
- 本软件主要进行科学计算（物理公式计算、数据拟合）和图形渲染（Canvas绘图、SVG渲染）
- 双核处理器可满足基础使用需求，但在进行大量数据拟合或生成复杂实验报告时，可能会出现轻微卡顿
- 六核及以上处理器可确保流畅的交互体验，特别是在仪器拖拽、光斑渲染和报告生成过程中

## 2. 内存 (RAM)

### 最低配置
- 内存容量：8 GB DDR4
- 内存频率：2400 MHz 及以上

### 推荐配置
- 内存容量：16 GB DDR4
- 内存频率：3200 MHz 及以上

### 说明
- 本软件运行时内存占用约为 500 MB - 1 GB
- 8 GB 内存可满足软件运行需求，但建议同时运行的其他程序不超过 2-3 个
- 16 GB 内存可确保在运行本软件的同时，流畅运行浏览器、办公软件等其他程序
- 建议使用双通道内存配置，可提升约 10-15% 的性能

## 3. 显卡 (GPU)

### 最低配置
- 显卡类型：集成显卡（Intel HD Graphics 530 或 AMD Radeon R7 及以上）
- 显存容量：共享内存（至少 512 MB）

### 推荐配置
- 显卡类型：独立显卡（NVIDIA GeForce GTX 1050 或 AMD Radeon RX 560 及以上）
- 显存容量：2 GB GDDR5 及以上

### 说明
- 本软件主要使用 CPU 进行计算，图形渲染通过浏览器内置的 Canvas 和 SVG 引擎实现
- 集成显卡可满足基础的图形渲染需求
- 独立显卡可提升图形渲染性能，特别是在放大光斑图样、绘制复杂光路图时
- 显卡需支持 WebGL 1.0 及以上标准

## 4. 显示器

### 最低配置
- 屏幕尺寸：19 英寸及以上
- 分辨率：1280 × 1024 及以上
- 屏幕比例：4:3 或 16:9
- 颜色深度：24 位（真彩色）

### 推荐配置
- 屏幕尺寸：21.5 英寸及以上
- 分辨率：1920 × 1080（全高清）及以上
- 屏幕比例：16:9
- 颜色深度：24 位（真彩色）
- 刷新率：60 Hz 及以上

### 说明
- 本软件主窗口尺寸为 1600 × 950 px，建议使用支持 1920 × 1080 分辨率的显示器
- 更高分辨率可提供更好的视觉体验，特别是在查看衍射光斑细节和实验报告时
- 颜色深度为 24 位可确保衍射光斑颜色的准确显示

## 5. 存储设备

### 最低配置
- 硬盘类型：机械硬盘 (HDD)
- 硬盘容量：500 GB 及以上
- 可用空间：至少 10 GB

### 推荐配置
- 硬盘类型：固态硬盘 (SSD)
- 硬盘容量：256 GB 及以上
- 可用空间：至少 20 GB

### 说明
- 本软件安装包大小约为 100 MB，运行时产生的缓存文件约为 50 MB
- 固态硬盘可显著提升软件启动速度和加载速度（从几秒缩短到几百毫秒）
- 建议将软件安装在固态硬盘上，以获得最佳性能

## 6. 输入设备

### 最低配置
- 键盘：标准键盘（支持基本输入）
- 鼠标：标准鼠标（支持左键、右键、滚轮）

### 推荐配置
- 键盘：机械键盘或薄膜键盘（支持舒适打字）
- 鼠标：光电鼠标或激光鼠标（支持高精度定位）

### 说明
- 本软件需要频繁使用鼠标进行仪器拖拽、游标定位、参数调节等操作
- 高精度鼠标可提升游标定位的准确性
- 滚轮功能用于放大窗口中的缩放操作，建议使用支持滚轮的鼠标

## 7. 网络连接

### 最低配置
- 网络类型：无（本软件为离线运行，无需网络连接）

### 说明
- 本软件为纯前端应用，无需后端服务器支持
- 安装和运行过程中无需网络连接
- 唯一需要网络的场景是通过浏览器访问远程部署版本

# 二、软件配置要求
# ========================================================

## 1. 操作系统

### 支持的操作系统
- Windows 10 64位（版本 1809 及以上）
- Windows 11 64位（版本 21H2 及以上）
- macOS 10.15 Catalina 及以上
- Linux（Ubuntu 20.04 LTS 及以上，Debian 10 及以上）

### 不支持的操作系统
- Windows 7 及以下版本
- macOS 10.14 及以下版本
- 32位操作系统

### 说明
- 本软件基于 Vue 3 和 Vite 构建，需要现代浏览器支持
- Windows 10 1809 及以上版本自带的 Edge 浏览器可满足需求
- 建议使用最新版本的操作系统，以获得最佳的安全性和兼容性

## 2. 浏览器

### 最低配置
- Microsoft Edge：版本 80 及以上
- Mozilla Firefox：版本 75 及以上
- Google Chrome：版本 80 及以上
- Apple Safari：版本 13 及以上

### 推荐配置
- Microsoft Edge：最新稳定版
- Google Chrome：最新稳定版
- Mozilla Firefox：最新稳定版

### 说明
- 本软件通过浏览器运行，需要支持 ES6+ JavaScript 语法和现代 Web API
- 推荐使用 Chromium 内核的浏览器（Edge 或 Chrome），性能最优
- 浏览器需启用 JavaScript 和 WebGL 功能
- 建议定期更新浏览器至最新版本

## 3. Node.js 环境

### 最低配置
- Node.js 版本：16.x LTS 及以上
- npm 版本：8.x 及以上

### 推荐配置
- Node.js 版本：20.x LTS
- npm 版本：10.x 及以上

### 说明
- 开发和构建本软件需要 Node.js 环境
- 普通用户运行已构建版本（dist 目录）无需安装 Node.js
- 建议使用 LTS 版本的 Node.js，稳定性更好
- 安装 Node.js 时，建议勾选"Add to PATH"选项

## 4. 其他软件

### 可选软件
- Git：用于版本控制（仅开发者需要）
- Visual Studio Code：用于代码编辑（仅开发者需要）
- PDF 阅读器：用于查看打印的实验报告（如 Adobe Acrobat Reader）

# 三、性能基准测试
# ========================================================

## 1. 启动时间

### 最低配置
- 开发模式启动：约 15-20 秒
- 生产模式启动：约 3-5 秒

### 推荐配置
- 开发模式启动：约 5-10 秒
- 生产模式启动：约 1-2 秒

## 2. 交互响应时间

### 最低配置
- 参数调节响应：约 100-200 ms
- 光斑渲染：约 200-300 ms
- 仪器拖拽：约 50-100 ms
- 报告生成：约 500-1000 ms

### 推荐配置
- 参数调节响应：约 50-100 ms
- 光斑渲染：约 100-150 ms
- 仪器拖拽：约 20-50 ms
- 报告生成：约 200-500 ms

## 3. 内存占用

### 正常运行
- 基础内存占用：约 500 MB - 1 GB
- 生成报告时峰值：约 1 GB - 1.5 GB
- 大数据拟合时峰值：约 1 GB - 2 GB

# 五、常见问题与解决方案
# ========================================================

## Q1：软件启动后界面显示不全？
A：检查显示器分辨率是否达到 1280 × 1024，建议设置为 1920 × 1080 或更高。

## Q2：光斑渲染卡顿？
A：降低浏览器缩放比例至 100%，或关闭其他占用大量资源的程序。

## Q3：仪器拖拽不流畅？
A：检查是否启用了浏览器的硬件加速功能，建议更新显卡驱动。

## Q4：报告生成速度慢？
A：确保计算机内存充足（至少 8 GB），建议使用固态硬盘。

## Q5：无法安装依赖？
A：确保 Node.js 版本为 16.x 及以上，使用 npm install --legacy-peer-deps 命令。

## Q6：浏览器提示安全限制？
A：确保浏览器版本为最新，启用 JavaScript 和 WebGL 功能。

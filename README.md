# 超声光栅衍射虚拟仿真实验 V4.0

## 项目简介

本项目是超声光栅衍射虚拟仿真实验的第四版，结合了第一版的测量界面、第二版的仪器仿真界面和新增的存档测量功能，提供完整的虚拟实验体验。项目基于 Vue 3 框架开发，支持 3D 仪器仿真、参数调节、衍射光斑仿真、数据测量与拟合分析、存档测量、实验报告生成等功能。

## 技术栈

- **框架**: Vue 3.4.21 (Composition API)
- **构建工具**: Vite 6.4.3
- **UI组件库**: Element Plus 2.6.3
- **工具库**: VueUse 10.9.0
- **3D渲染**: Three.js 0.165.0
- **动画库**: Tween.js 18.6.4
- **语言**: JavaScript (ES6+)

## 功能特点

### 一、仪器仿真界面

- **3D仪器场景**：使用 Three.js 构建三维仪器场景，支持旋转、缩放、平移
- **仪器拖拽与布局**：从左侧仪器库拖拽激光、平行光管、超声光栅水槽、望远镜、CCD相机、信号发生器、计算机等仪器到实验桌
- **仪器交互控制**：激光开关、水槽参数调节（浓度、频率、振幅）、望远镜对焦、CCD相机显示衍射光斑
- **仪器属性调节**：支持鼠标滚轮缩放仪器、拖拽移动、旋转调节朝向、固定位置
- **支架结构**：所有仪器配备银色金属支架（轭架、立柱、高度调节器、底座），支架随仪器缩放而变化
- **光学连接效果**：激光开启后显示红色渐变光束，光束跟随激光器移动和旋转
- **实验模式选择器**：顶部工具栏提供三个实验方向按钮（光波长影响、超声频率影响、液体浓度影响），选中后自动锁定非变量参数
- **实验操作指南**：点击操作指南按钮弹出详细操作说明
- **仪器库可关闭**：支持隐藏/显示仪器库面板
- **深色科技风背景**：非白色背景，木质操作台面
- **状态保持**：使用 KeepAlive 保持组件状态，切换视图时仿真进度不会清空

### 二、数据测量界面

- **参数设置**：液体浓度（0-30 wt%）、入射波长（380-700 nm）、超声频率（4-15 MHz）、超声振幅、水槽到光屏距离、狭缝宽度
- **常温设定**：环境温度固定为 20°C，绿色高亮显示且不可编辑
- **衍射光斑图样**：多层渐变效果（外光晕→中光晕→垂直渐变主体→核心高光→白色亮芯），颜色随波长变化，光纹长度 85%，中心最亮两端逐渐变暗
- **游标读数功能**：两个圆环形游标，支持激活模式、左右调节按钮、自动读数（点击按钮自动计算+1级和-1级衍射光斑位置）
- **衍射光强分布曲线**：深蓝色曲线，半透明填充，横坐标 -15~15 mm，纵坐标 -0.05~1.05，白色背景
- **数据拟合分析**：三种实验模式（液体浓度影响、光波长影响、超声频率影响），散点+拟合曲线

### 三、存档测量功能

- **存档创建**：在测量界面收集至少3组浓度实验数据后，点击"创建存档"生成校准曲线
- **存档列表**：显示所有存档卡片，包含数据点数量、浓度范围、声速范围、拟合公式、曲线预览、创建时间，支持删除存档
- **存档测量**：进入存档测量界面，系统随机生成未知浓度，用户通过测量衍射光斑计算声速，再根据校准曲线反推浓度
- **校准曲线显示**：实时显示浓度-声速校准曲线和当前测量点
- **置信度显示**：显示计算浓度的置信水平

### 四、分析与验证程序

- **数据分析指标**：实验声速、理论声速、相对误差、标准差、变异系数、中位数、极差、四分位距
- **分模式验证逻辑**：波长/频率模式验证声速恒定，浓度模式验证线性拟合参数
- **拟合参数验证**：斜率、截距误差分析
- **验证结果与建议**：数据一致性评级（优秀/良好/一般/较差），针对性改进建议

### 五、实验报告生成

- **三段式报告**：根据三个实验方向分别生成报告段落
- **每段包含**：实验目的、实验原理、光路流程图（SVG绘制）、数据表格、拟合结果、分析与结论
- **报告状态**：显示每段报告的完成状态（已完成/部分完成/未开始）
- **导出功能**：支持打印报告和保存为HTML文件

### 六、交互功能

- **双击放大**：衍射光斑、光强曲线、拟合图表、CCD相机光斑均支持双击放大，支持滚轮缩放、拖拽平移、双击复位、点击空白处或按ESC关闭
- **提示与通知**：参数超出范围提示、操作成功/失败通知
- **响应式布局**：三栏布局（左侧30%、中间45%、右侧25%）

## 使用说明

### 一、欢迎界面
1. 启动后进入欢迎界面，点击"开始实验"进入实验界面

### 二、仪器仿真界面操作
1. 默认进入仪器仿真界面，点击顶部导航可切换到"测量界面"、"实验报告"、"存档测量"
2. **选择实验方向**：在仪器仿真界面顶部选择实验方向（光波长影响/超声频率影响/液体浓度影响）
3. **仪器操作**：
   - 从左侧仪器库点击或拖拽仪器到实验桌
   - 双击仪器打开控制面板
   - 滚轮缩放选中的仪器（未选中时滚轮控制场景缩放）
   - 拖拽移动仪器位置
   - 旋转调节仪器朝向
   - 点击"固定"按钮锁定仪器位置
4. **按步骤操作**：开启激光→调节液体浓度→设置超声频率/振幅→调节水槽到光屏距离/狭缝宽度→对焦接收屏
5. **CCD相机对焦**：双击CCD相机打开对焦界面，对焦成功后显示衍射光斑，数据自动同步到测量界面

### 三、测量界面操作
1. 设置实验参数
2. 点击"运行仿真"生成衍射图样
3. 使用游标测量光斑位置（激活游标后点击光斑图放置）
4. 点击"自动读数"或手动调节游标
5. 点击"保存数据"记录测量结果
6. 点击"执行拟合"生成拟合曲线
7. 点击"执行验证"进行数据分析与验证
8. 双击图像可放大查看

### 四、存档测量操作
1. 在测量界面收集至少3组浓度实验数据
2. 点击"创建存档"生成校准曲线
3. 在存档列表点击"进入测量"
4. 系统随机生成未知浓度，测量衍射光斑计算声速
5. 根据校准曲线反推浓度，查看置信度

### 五、生成实验报告
1. 点击顶部导航栏的"实验报告"按钮
2. 查看三段报告内容（浓度影响、波长影响、频率影响）
3. 支持打印或保存报告

## 物理原理

### 光栅方程
```
λₛ × sinθₖ = kλ
```

### 近似条件（θₖ很小时）
```
sinθₖ ≈ tanθₖ = Dₖ / (2L)
```

### 条纹间距公式
```
D = 2kλLf / v
```

### 声速公式（浓度模式）
```
v = 1500 + 10 × c
```

其中：
- λₛ：超声光栅常数
- θₖ：k级衍射角
- k：衍射级次（通常取k=1）
- λ：入射光波长
- D：±1级衍射条纹间距
- L：水槽到光屏距离
- f：超声频率
- v：声速
- c：液体浓度（wt%）
